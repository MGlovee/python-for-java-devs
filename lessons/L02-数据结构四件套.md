# L02 · 数据结构四件套与推导式

> 读 40 分钟 · 练 50 分钟
> 对应原文：`Day01-20/08`~`13`（6 篇、约 1534 行）→ 压缩成这一页

Java 的集合框架是"接口 + 实现类"的九宫格；Python 只有四个内置容器加三个 `collections` 里的补位选手，
90% 的场景就是它们。**这一课真正的增量是推导式**——它是 Python 表达"把一个集合变成另一个集合"的默认方式，
地位相当于你的 Stream API，但没有装箱、没有 lambda 捕获限制、也不用 `.collect()` 收尾。

## ② 差异地图

### 四件套一览

| Python | 字面量 | 有序？ | 可变？ | 允许重复？ | Java 最近的东西 |
|---|---|---|---|---|---|
| `list` | `[1, 2]` | 插入序 | ✅ | ✅ | `ArrayList` |
| `tuple` | `(1, 2)` | 插入序 | ❌ | ✅ | 没有对等物（记录/多返回值） |
| `dict` | `{"k": 1}` | **插入序**（3.7+ 语言级保证） | ✅ | 键不可重复 | `LinkedHashMap` |
| `set` | `{1, 2}` | 无序 | ✅ | ❌ | `HashSet` |
| `frozenset` | `frozenset({1})` | 无序 | ❌ | ❌ | 不可变 Set，可当 dict 的键 |

补位选手（`from collections import ...`）：

| 类型 | 解决什么问题 | 一行示例 |
|---|---|---|
| `Counter` | 计数（Java 要 `merge(k, 1, Integer::sum)`） | `Counter("abracadabra")["a"] == 5` |
| `defaultdict` | 键不存在时自动给默认值，免去 `if k not in d` | `defaultdict(list)["新键"].append(1)` |
| `deque` | 两端 O(1)；**`list.pop(0)` 是 O(n)** | `deque([1,2,3]).popleft()` |
| `namedtuple` / `dataclass` | 轻量记录类型 | `Point = namedtuple("Point", "x y")` |
| `OrderedDict` | 只在需要"移动顺序/相等性看顺序"时才用 | 普通场景 `dict` 已够用 |

### 切片：Python 独有的手感

```python
s = "0123456789"
s[2:5]     # '234'   左闭右开
s[:3]      # '012'   从头
s[7:]      # '789'   到尾
s[::2]     # '02468' 步长 2
s[::-1]    # '9876543210' 反转 —— 这就是 Python 的"反转字符串"
s[-1]      # '9'     负索引从尾部数
s[100]     # IndexError！越界直接抛
s[20:30]   # ''      但切片越界不抛，返回空 —— 两者行为不一致，记住
```

`list`、`tuple`、`str`、`bytes` 全用同一套切片语法。切片返回**新对象**，不是视图。

### 推导式（本课主角）

```java
List<Integer> squares = nums.stream().map(n -> n * n).collect(toList());
List<Integer> evens   = nums.stream().filter(n -> n % 2 == 0).collect(toList());
Map<String, Integer> byLen = words.stream().collect(toMap(w -> w, String::length));
Set<Integer> uniq     = nums.stream().collect(Collectors.toSet());
```

```python
# Python —— 没有装箱、没有 collect、没有方法引用
squares = [n * n for n in nums]
evens   = [n for n in nums if n % 2 == 0]
by_len  = {w: len(w) for w in words}
uniq    = {n for n in nums}
matrix  = [[r * c for c in range(3)] for r in range(3)]        # 嵌套
cleaned = [x.strip() for line in lines for x in line.split()]  # 双层 = 扁平化
```

顺序和 Stream 相反：**先写"要什么"（表达式），再写"从哪来"（for），最后写"筛什么"（if）**。
一条推导式里最多两层 `for`，再深就该写成普通循环——可读性优先，这是 PEP 20 的规矩。

生成器版本把 `[]` 换成 `()`：`(n * n for n in nums)` **不立刻算**，惰性产出，处理大文件时用它（L07 展开）。

### 常用操作对照（只列你天天要用的）

```python
xs = [3, 1, 2]
xs.append(4)          # 尾加 O(1)
xs.insert(0, 9)       # 头插 O(n) —— 频繁头插请换 deque
xs.remove(1)          # 删第一个值等于 1 的，没有则 ValueError
xs.pop()              # 弹出末尾
xs.extend(other)      # 批量追加，等价 other 循环 append
1 in xs               # 成员判断：list O(n)，set/dict O(1) ← 这是最容易写成性能陷阱的地方
sorted(xs)            # 返回新列表；xs.sort() 原地。Java 的 Collections.sort 对等
sorted(xs, key=lambda p: p.age, reverse=True)   # Comparator.comparing 的对等物
min(xs) / max(xs) / sum(xs) / len(xs) / any(...) / all(...)
reversed(xs)          # 惰性迭代器，不是列表
list(set(xs))         # 去重（顺序丢失）。要保序去重：dict.fromkeys(xs)
```

排序稳定性：Python 的 `sort` **稳定**（TimSort），Java 的 `List.sort` 也稳定，这点一致，可以放心多级排序。

### `==` 与 `is`，以及可变默认值

```python
[1, 2] == [1, 2]     # True   值相等，对等 Objects.equals
a is b               # 判断是不是同一个对象，只用于 None/单例
x is None            # ✅ 判空的标准写法
```

以及 Python 最著名的一颗雷：

```python
def bad(item, bucket=[]):        # ❌ 默认值在函数**定义时**求值一次，所有调用共享同一个列表
    bucket.append(item); return bucket
def good(item, bucket=None):     # ✅ 标准解法
    bucket = [] if bucket is None else bucket
    bucket.append(item); return bucket
```

Java 没有这个问题，因为参数没有默认值机制。见到 `def f(x=[])` 或 `def f(x={})` 就是 bug。

## ⑤ 三个 Java 老手必踩的坑

1. **`list` 当队列用 `pop(0)`**。ArrayList 头删也是 O(n)，Python 里更痛，因为看起来很轻。换 `collections.deque`。
2. **在 `for` 里删正在遍历的列表元素**。要么用推导式生成新列表（`xs = [x for x in xs if keep(x)]`），
   要么遍历副本 `for x in xs[:]:`。直接 `xs.remove(x)` 会漏元素——和 Java 的 `ConcurrentModificationException` 不同，**Python 不报错，静默出错**。
3. **可变对象当 dict 的键 / set 的元素**。`list`、`dict`、`set` 都不可哈希，`TypeError: unhashable type`。
   要当键就用 `tuple` 或 `frozenset`；`dict`/`set` 的成员判断是 O(1)，别用 `list` 硬扛。

## ⑥ 现在回看开头 3 题

1. `a` 也是 `[1, 2, 3, 4]`。Python 变量是**引用**，`b = a` 不复制，和 Java 的 `List b = a` 一模一样。
   要复制：`b = a.copy()` 或 `b = a[:]`（浅拷贝），深拷贝 `copy.deepcopy(a)`。
2. `d["y"]` 抛 `KeyError`；`d.get("y")` 返回 `None`（可给第二参数当默认值）。Java 的 `map.get` 只对应后者。
3. `{1, 2, 2, 3}` → `{1, 2, 3}`（set 字面量，重复自动消失）；但 `{}` 是**空 dict**，空 set 只能写 `set()`。
