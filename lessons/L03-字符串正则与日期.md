## ② 差异地图

### 字符串方法：Java → Python

| 你想干什么 | Java | Python | 提醒 |
|---|---|---|---|
| 长度 | `s.length()` | `len(s)` | `len` 是内置**函数**，不是方法 |
| 取下标 | `s.charAt(3)` | `s[3]` | 没有 `char`，`s[3]` 还是 `str` |
| 截取 | `s.substring(2, 5)` | `s[2:5]` | 切片左闭右开，还能 `s[::-1]` 反转 |
| 拼接循环 | `StringBuilder.append` | `parts.append` + `''.join(parts)` | `str` 不可变，`+=` 是 O(n²) |
| 找子串 | `indexOf`（找不到 **-1**） | `find`（找不到 **-1**）/ `index`（找不到 **ValueError**） | `in` 判存在：`'wo' in s` |
| 大小写 | `toUpperCase/toLowerCase` | `upper()` / `lower()` / `title()` / `capitalize()` | 全小写比较：`s.lower() == t.lower()` |
| 去空白 | `trim()` / `strip()` | `strip()` / `lstrip()` / `rstrip()` | `strip('ab')` 是按**字符集**剥，不是剥前缀串 |
| 判断内容 | 正则或手写 | `isdigit()` `isalpha()` `isalnum()` `startswith()` `endswith()` | `startswith` 可传元组：`f.endswith(('.png', '.jpg'))` |
| 补齐宽度 | `String.format('%-10s')` | `ljust()` `rjust()` `center()` `zfill()` | 也可用 f-string `{x:<10}` |
| 替换 | `s.replace("a","b")`（字面） | `s.replace('a','b', count)`（字面，可限次数） | 正则替换是 `re.sub` |
| 拆分 | `s.split(",")` ← **参数是正则** | `s.split(',')` ← **参数是字面串**；`split()` 不带参按任意空白切且丢掉空串 | 要用正则切：`re.split(r'\d+', s)` |
| 合并 | `String.join("-", list)` | `'-'.join(list)` | join 是**分隔符**的方法，元素必须是 str |
| 编码 | `new String(bytes, UTF_8)` | `s.encode('utf-8')` / `b.decode('utf-8')` | `str` 与 `bytes` 是两种类型，不自动转换 |

### f-string：比 Java 的 `String.format` 好用一个数量级

```python
name, score, ratio, dt = 'Alice', 3.1415926, 0.123, datetime(2024, 3, 15, 9, 23)
f'{score:.2f}'        # '3.14'      保留两位
f'{score:+.2f}'       # '+3.14'     强制符号
f'{1234567:,}'        # '1,234,567' 千分位
f'{ratio:.2%}'        # '12.30%'    百分比
f'{123456789:.2e}'    # '1.23e+08'  科学计数
f'{123:0>10d}'        # '0000000123' 补零到 10 位；x< 右补 x，^ 居中
f'{name:>8}'          # '   Alice'  右对齐宽 8
f'{dt:%Y-%m-%d %H:%M}'# '2024-03-15 09:23' 冒号后面直接跟 strftime 格式符
f'{score=}'           # 'score=3.1415926'   调试神器，连变量名一起打
```

### 正则：`re` 模块与 `java.util.regex` 的 API 形状不同

| 需求 | Java | Python |
|---|---|---|
| 编译 | `Pattern.compile(p)` | `re.compile(p)`（重复使用的模式一定要编译） |
| 整串匹配 | `m.matches()` | `re.fullmatch(p, s)` |
| 从**串首**匹配 | 无直接对应 | `re.match(p, s)` |
| 任意位置找第一个 | `m.find()` | `re.search(p, s)` |
| 找所有 | `m.results()` 流 | `re.findall(p, s)`（列表）/ `re.finditer(p, s)`（匹配对象迭代器） |
| 替换 | `s.replaceAll(p, r)` | `re.sub(p, r, s, count=0, flags=...)` |
| 按模式拆 | `s.split(p)` | `re.split(p, s, maxsplit)` |
| 取分组 | `m.group(1)` / `m.group("name")` | `m.group(1)` / `m['name']`，一次全拿用 `m.groupdict()` |
| 忽略大小写 | `CASE_INSENSITIVE` | `flags=re.I`（可 `re.I \| re.M` 叠加） |

常用元字符跟你熟的几乎一样：`.` `\w` `\d` `\s` `[]` `[^]` `{m,n}` `*+?` `|` `()` `(?:)`。
**只有两处要重新记**：非贪婪是加 `?`（`.*?`），前后向查找是 `(?=...)` `(?<=...)` `(?!...)` `(?<!...)`——
手机号这种"两侧不能是数字"就靠 `(?<!\d)` 和 `(?!\d)`，`\b` 在这里不顶用。

### 日期：`java.time` 的心智要换一套字母

| 需求 | Java | Python |
|---|---|---|
| 今天 | `LocalDate.now()` | `date.today()` |
| 年月日时分秒 | `LocalDateTime` | `datetime`（一个类全包） |
| 时长 | `Duration` / `Period` | `timedelta`（两者合一） |
| 解析 | `DateTimeFormatter.ofPattern("yyyy-MM-dd")` | `datetime.strptime(s, '%Y-%m-%d')` |
| 输出 | `dt.format(fmt)` | `dt.strftime('%Y-%m-%d')` |
| 加减 | `dt.plusDays(1)` | `dt + timedelta(days=1)` |
| 两日期相差 | `ChronoUnit.DAYS.between(a, b)` | `(b - a).days`（得 `timedelta`） |
| 星期 | `DayOfWeek` 枚举 | `d.weekday()`（**周一=0**）/ `isoweekday()`（周一=1） |
| 当月天数 | `lengthOfMonth()` | `calendar.monthrange(y, m)[1]` |
| 时区 | `ZonedDateTime` | `zoneinfo.ZoneInfo`（3.9+）；`datetime.now()` 默认**不带时区** |
| 相对日期 | `ChronoUnit` + 手写 | `pip install python-dateutil`（`parser.parse` / `relativedelta`），标准库没有 |

> `strptime` / `strftime` 的格式符是 C 的 `%` 字母表，跟 Java 的 `yMD` 字母表**完全不通用**：
> `%Y` 四位年、`%m` 补零月、`%d` 补零日、`%H/%M/%S` 时分秒、`%f` 微秒。写错了不报语法错，只在解析时炸。

## ⑤ 三个 Java 老手必踩的坑

1. **`str.split` 不是正则**。Java 的 `String.split(",")` 收到的是正则，你会习惯性写
   `s.split('.')` —— 在 Python 里这行合法且按字面点号切，反而是你想要的；但 `s.split('\|')`
   在 Java 里切的是竖线，在 Python 里切的是字面 `\|` 两个字符。凡是要正则，一律 `re.split`。
2. **正则串必须加 `r` 前缀**。写 `'\d+'` 而不是 `'\\d+'`：从 3.12 起无效转义直接 `SyntaxWarning`，
   将来会变成语法错误。同一坑还顺手砸你一次 Windows 路径 —— `print('C:\new\test')` 里的 `\n` 和
   `\t` 已经被转义了，路径必须写 `r'C:\new\test'`。
3. **`re.match` 找到就返回"部分匹配"的对象**，它不要求整串命中，也不要求命中到结尾。
   校验用户输入用 `re.fullmatch`；从一堆文本里捞东西用 `re.search` / `re.findall`。
   把 Java 的 `matches()` 直觉映射到 `match()` 上，是你今天最可能写出来的 bug。

## ⑥ 现在回看开头 3 题

1. **返回 `None`**。`match` 从字符串开头开始试，开头是"订单"两个字，匹配失败。
   换成 `re.search(r'\d+', s)` 才拿到 `'123'`。
2. 因为 Python 的 `str` 是**序列**，`join` 定义在分隔符上、读作"用我把这些元素串起来"：
   `'-'.join(['a','b','c'])` → `'a-b-c'`。列表里混进非 str 元素会 `TypeError`，先 `map(str, xs)`。
3. **`314%`**。`:.0%` 是"按百分比格式、0 位小数"，先乘 100 再取整。想要 `314.16%` 写 `:.2%`。
