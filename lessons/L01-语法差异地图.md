## ② 差异地图（只列你缺的那 20%）

| 主题 | Java | Python | 一句话提醒 |
|---|---|---|---|
| 代码块 | `{}` | **缩进 4 空格** | 缩进就是语法，混用 Tab 和空格直接 `IndentationError` |
| 语句结尾 | `;` | 换行即结束 | 长行用 `\` 或括号续行 |
| 变量声明 | `int x = 1;` | `x = 1` | 类型挂在**对象**上，不挂在变量上；变量只是标签 |
| 类型系统 | 静态强类型 | **动态强类型** | 不会自动转 `int`→`str`，`1 + "1"` 两边都报错 |
| 整数 | `int`/`long` 会溢出 | `int` 任意精度 | 大数运算不需要 `BigInteger` |
| 除法 | `7/2 == 3` | `7/2 == 3.5` | 想要整除用 `//`，注意它对负数**向下取整**：`-7//2 == -4` |
| 取模 | 结果符号跟被除数 | 结果符号跟**除数** | `-7 % 3 == 2`，`7 % -3 == -2` |
| 自增 | `i++` | **没有** | 只有 `i += 1` |
| 布尔 | `true/false` | `True/False` | 大写开头；`and / or / not` 是单词 |
| 空值 | `null` | `None` | 判空写 `if x is None:`，**不要**写 `== None`，也不要写 `if x:`（0、`[]`、`""` 都会误判成 None） |
| 真值 | 只能 boolean | **一切对象可真假** | `0, 0.0, "", [], {}, set(), None` 为假；其余为真。`if items:` 是地道写法 |
| 字符 | `char` | 没有 char，长度 1 的 `str` | `s[0]` 得到 `'H'` 还是字符串 |
| 字符串 | 可变性靠 `StringBuilder` | `str` 不可变 | 拼接循环里用 `''.join(parts)`，别用 `+=` |
| 三元 | `a ? b : c` | `b if a else c` | 读的顺序和 Java 反 |
| 交换 | 临时变量 | `a, b = b, a` | 元组解包，不需要 temp |
| 块级作用域 | 有 | **没有**，只有函数级 | `for` 循环里定义的变量，出了循环还在 |
| 接口/抽象类 | `interface`/`abstract` | 鸭子类型 / `ABC` / `Protocol` | L05 细讲 |

### 分支与循环的语法对照

```java
// Java
if (score >= 90) { ... } else if (score >= 60) { ... } else { ... }
for (int i = 0; i < 10; i++) { ... }
for (String s : list) { ... }
while (running) { ... }
switch (op) { case "+": ... break; default: ... }
```

```python
# Python —— 注意 elif 是三个字母，default 叫 else
if score >= 90:
    ...
elif score >= 60:
    ...
else:
    ...

for i in range(10):          # range 是左闭右开：0..9
    ...

for s in items:              # 直接遍历可迭代对象，没有"迭代器对象"这个词
    ...

while running:
    ...

match op:                    # Python 3.10+ 才有；老代码里全是 if/elif
    case "+": ...
    case "-" | "−": ...
    case _: ...              # _ 是 default，且不需要 break
```

### Python 独有的两个东西

**`for/while ... else`**：循环**没有被 break 打断**时执行 `else`。Java 没有对应物，第一次见一定懵。把它读作"否则（我没找到）"：

```python
for n in range(2, number):
    if number % n == 0:
        print(f"{number} 不是素数，最小因子 {n}")
        break
else:
    print(f"{number} 是素数")   # 只有整趟循环没 break 才走到这里
```

**可迭代对象家族**：`range()` 不产生列表，它是一个惰性序列；`enumerate()` 和 `zip()`
是替代 Java 下标循环的主力。**能用 `enumerate` 就别写 `range(len(...))`**：

```python
for i, name in enumerate(names, start=1):   # i 从 1 开始
    print(i, name)

for name, score in zip(names, scores):      # 并行遍历，长度不等时截断到短的
    print(name, score)
```

## ③ 完整样例：读 → 跑 → 改

下面这段是"Java 味"和"Python 味"的对照。先跑，再改数字，最后照着改成 `temperature.py`。

```python
# drills/L01/worked_example.py 可以直接跑：py drills/L01/worked_example.py
def classify(numbers: list[int]) -> dict[str, int]:
    """统计正数、负数、零的个数 —— 一次讲完缩进/真值/字典/循环。"""
    result = {"positive": 0, "negative": 0, "zero": 0}
    for n in numbers:
        if n > 0:
            result["positive"] += 1
        elif n < 0:
            result["negative"] += 1
        else:
            result["zero"] += 1
    return result


def fib_steps(n: int) -> list[int]:        # while 循环 + 元组交换
    a, b = 0, 1
    out = []
    while a < n:
        out.append(a)
        a, b = b, a + b                     # 没有临时变量
    return out


if __name__ == "__main__":                  # 相当于 Java 的 public static void main
    print(classify([3, -1, 0, 7, -8, 0]))
    print(fib_steps(50))
    print(f"第 {len(fib_steps(1000))} 项斐波那契不超过 1000")
```

## ⑤ 三个 Java 老手必踩的坑

1. **`/` 已经是真除法**。Java 里 `1/2 == 0` 的直觉会让你算平均分时得到奇怪结果。整数除法请明确写 `//`，并记住它**向下取整**（往负无穷方向），不是"截断小数"：`-7 // 2 == -4`，而 Java 的 `-7 / 2 == -3`。
2. **`if x:` 不等于 `if x != None`**。空列表、空字符串、`0` 都会走 false 分支。判"没有值"要写 `if x is None:`，判"空集合"才写 `if not x:`。
3. **循环变量不会出作用域**。Java 里 `for (int i...)` 的 `i` 出了循环就没了；Python 里 `for i in range(10):` 之后 `i` 还等于 `9`。别依赖它，也别说它泄漏。

## ⑥ 现在回看开头 3 题

1. `-7 % 3` → **`2`**。Python 取模结果符号跟随除数（数学上是"带余除法的非负余数"）。
2. `7 // 2` → **`3`**；`7 ** 2` → **`49`**。`**` 是幂运算，Java 里得写 `Math.pow`。
3. 空列表 `[]` → **不进**。`[]` 是 falsy，`if x:` 读作"如果 x 非空"。
