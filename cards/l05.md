# L05 闪卡 · 面向对象 Python 风格

> 用法：盖住右列，看左列自问自答，答完再对。做错的那行，在"错"列打 ×。
> 复习节奏：完成当天不算，D+1、D+2、D+4、D+7 各过一遍（`py progress.py review` 会告诉你今天该翻哪张）。

| # | 问 | 答 | 错 |
|---|---|---|---|
| 1 | `Point(1, 2)` 时谁真的创建了对象？`__init__` 该返回什么 | `__new__` 创建，`__init__` 只初始化且必须返回 `None`（返回别的会 TypeError） | |
| 2 | 实例方法为什么每个都要写 `self` | 没有隐式 this：`obj.f(x)` 就是 `Cls.f(obj, x)`。漏写 self 它就变成普通函数 | |
| 3 | `class A: items = []` 的 `items` 属于谁 | 类属性，**所有实例共享**。实例字段必须写在 `__init__` 里的 `self.items` | |
| 4 | 只写 `__eq__` 会发生什么 | 实例不可哈希：`__hash__` 被自动置为 None，进 set/dict 直接 TypeError | |
| 5 | `__str__` 和 `__repr__` 的分工 | `__str__` 给人看（`print`、f-string 用）；`__repr__` 给开发者看（应能重建对象）。**没写 `__str__` 时 print 退到 `__repr__`**；列表里的元素永远用 `__repr__` | |
| 6 | `sorted(objs)` 至少要实现哪个魔术方法 | `__lt__` 一个就够。别的比较可用 `functools.total_ordering` 或 `@dataclass(order=True)` 补 | |
| 7 | `len(obj)`、`obj[i]`、`obj(1)` 分别调用什么 | `__len__`、`__getitem__`、`__call__` | |
| 8 | 为什么 `if obj:` 对空容器为假 | 没写 `__bool__` 时退到 `__len__`，长度为 0 即假 | |
| 9 | `@property` 解决什么 Java 问题 | 用属性语法暴露计算/校验逻辑。以后要加校验改成 property，**调用方代码不用动**；`r.area` 不加括号 | |
| 10 | `@staticmethod` 和 `@classmethod` 区别 | static 不接 self 也不接 cls；classmethod 第一个参数是 `cls`，工厂方法用它才能被子类复用 | |
| 11 | Python 的 `super()` 和 Java 的 `super` 本质差别 | Java 绑死直接父类；Python 返回**MRO 上下一个类**的代理 —— 多继承/Mixin 全靠它 | |
| 12 | `class A; class B(A); class C(A); class D(C, B)`，`D.__mro__` | `(D, C, B, A, object)`。C3 线性化，基类书写顺序决定优先级 | |
| 13 | `ABC` 和 `Protocol` 选哪个 | `ABC` 是名义类型（必须继承，`@abstractmethod` 拦实例化）；`Protocol` 是结构类型（长得像就算，不用继承），需要 `isinstance` 时加 `@runtime_checkable` | |
| 14 | `@dataclass` / `frozen=True` / `order=True` 各给什么 | 基础版给 `__init__/__repr__/__eq__`；`frozen` 再加只读 + `__hash__`；`order` 再加 `__lt__` 等比较 | |
| 15 | `__slots__ = ('x','y')` 得到什么 | 没有 `__dict__`：省内存、禁止动态挂别的属性（`p.z = 3` → AttributeError） | |
| 16 | 私有属性怎么实现 | `__name` 走名称改写（可用 `_Cls__name` 强访），`_name` 只是约定。Python 没有真正的 private | |
| 17 | `type(x) is C` 和 `isinstance(x, C)` 差别 | 前者只认精确类型，后者认继承和 ABC/Protocol 注册。业务代码一律用 `isinstance` | |
| 18 | Enum 成员能直接 `a < b` 吗 | 不能，TypeError。要比 `a.value < b.value`；遍历用 `for e in Color:` | |

## 一句话自检（背不出就回讲义 ⑤）

- 三个坑：类属性是共享的可变对象、写了 `__eq__` 就丢了 `__hash__`、`super()` 是 MRO 的下一个而不是爸爸。
