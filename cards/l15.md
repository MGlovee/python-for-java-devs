| # | 问 | 答 | 错 |
|---|---|---|---|
| 1 | ndarray 跟 `int[][]` / `List<Integer>` 的根本差别 | 一块**连续内存** + `(shape, strides)` 元数据；无对象头、无装箱，所以能整块向量化 | |
| 2 | `np.array([[1,2],[3,4]])` 的 shape / dtype / ndim | `shape=(2, 2)`、`dtype=int64`、`ndim=2`；一个数组只能一种 dtype，混入 float 会整体升级 | |
| 3 | `axis=0` 和 `axis=1` 谁是谁，结果形状怎么算 | axis 是**被压掉的那根轴**：`axis=0` 沿行方向压缩 → 每列一个值（形状 `(cols,)`）；`axis=1` → 每行。要保住 `(rows, 1)` 用 `keepdims=True` | |
| 4 | 广播一句话规则 | 形状从**右往左**逐位对齐：相等通过，是 1 或缺席就复制补齐，对不上抛 `ValueError`（`(2,3)` 减 `(2,)` 就是这么炸的） | |
| 5 | `grid = base.reshape(2,3)` 后 `grid[0,0]=99`，base 变吗 | **变**。reshape 与切片返回**视图**，共用一块内存；要独立副本用 `.copy()`，检测用 `np.shares_memory()` | |
| 6 | 布尔索引 / 花式索引返回视图还是拷贝，形状呢 | 都是**拷贝**（改了不影响原数组），且 `arr[arr > 2]` 的结果永远降成 1 维 | |
| 7 | `arr[arr > 1 and arr < 5]` 错在哪 | 数组上 `and`/`or` 无法真值判断（`ValueError: truth value ... is ambiguous`）。写 `(arr > 1) & (arr < 5)`，条件逐个加括号 | |
| 8 | `np.sort` / `np.argsort` / `argmax` 分别给什么 | `sort` 给排好的**值**；`argsort` 给排好的**下标**（排完还知道每行是谁）；`argmax(axis=1)` 给每行最大值下标 | |
| 9 | 降序且并列保持原顺序怎么写 | `np.argsort(-scores, kind="stable")`。`np.argsort(scores)[::-1]` 会把并列项一起反转，是错的 | |
| 10 | numpy 2 / pandas 3 里被删掉、被改名的 API | `ndarray.ptp()` 没了（改 `np.ptp(a)`）、`DataFrame.applymap` 没了（改 `DataFrame.map`） | |
| 11 | DataFrame ≈ Java 里的什么 | 带列名的 `List<Map>`，但列名与行索引是**一等公民**，每列是一个带索引的 `Series`，缺失值有专门语义 | |
| 12 | 不落地读 CSV，以及它的自动行为 | `pd.read_csv(io.StringIO(text))`：第一行当表头、数字列自动转型、空字段自动当缺失 | |
| 13 | 取两列 / 条件筛选怎么写 | `df[["a","b"]]`（列顺序按你给的来）、`df[df["a"] > 150]`（NaN 行因比较恒 False 被滤掉） | |
| 14 | `df["a"][mask] = 0` 在 pandas 3 的结果，正确写法 | copy-on-write 下中间对象永远是拷贝 → 只发 `ChainedAssignmentError` 告警，**数据没改**。写 `df.loc[mask, "a"] = 0` 或 `df.assign(a=...)` | |
| 15 | `groupby().agg()` / `merge` 对应 Java、SQL 的什么 | `Collectors.groupingBy + reducing` / `GROUP BY + COUNT/SUM/AVG`；`pd.merge(..., on=, how="inner"/"left")` ≈ SQL JOIN（pandas 3 不再把 `on` 列提到最前，列序按左表） | |
| 16 | `groupby` 里的 `count` 算不算 NaN | **不算**。非空个数，`sum`/`mean` 也自动跳过 NaN，与 SQL 一致（P3 的"研发 count=2"就是这个） | |
| 17 | 判缺失只能用哪三件套；`value_counts()` 干什么 | `isna()` / `fillna()` / `dropna()`——`x == None`、`x == np.nan` 永远 False，`NaN != NaN`；`value_counts()` ≈ `GROUP BY col COUNT(*)` 且默认按次数降序 | |
| 18 | 什么时候**别**用 pandas；统计结果为什么 `json.dumps` 会炸 | 几百行只读几列、只要一个均值、流式逐条、在意部署体积、需要事务与复杂关联（用标准库 `csv` / SQL）。`np.int64` 不是 `int`，出口统一 `int()`/`float()` | |

## 一句话自检（背不出就回讲义 ⑤）

- 三个必踩的坑：切片/`reshape` 是**视图**不是拷贝、链式赋值在 copy-on-write 下静默失效、`axis` 方向用反不报错只在广播时才炸。
