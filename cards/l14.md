| # | 问 | 答 | 错（最常见的误答） |
|---|---|---|---|
| 1 | pytest 怎么发现用例 | 文件 `test_*.py` + 函数 `test_*`，测试类要 `Test*` 且不能写 `__init__`；靠**命名约定** | 以为要像 JUnit 那样加 `@Test` 注解 |
| 2 | 裸 `assert a == b` 失败为什么能打印左右值 | pytest 导入测试模块时**重写 AST**，把 `==` 换成分别求值两边的内部比较 | 以为靠运行时反射，或以为只有 `assertEquals` 才有详细信息 |
| 3 | 断言消息怎么写？Python 的 assert 何时失效 | `assert a == b, "消息"`，逗号在**外层**；默认真执行（不像 Java 要 `-ea`），但 `python -O` **整行删掉** | 写成 `assert (a == b, "消息")` → 断言的是元组，恒真、测试永远绿；或拿 assert 当业务校验 |
| 4 | 期望异常怎么写（练习 7 的语义） | `with pytest.raises(X, match="0~1") as e:`；块内**没抛 = 失败**；抛了别的类型 = 让它冒出去；`e.value` 是异常对象 | 用 `try/except: pass` 兜住；以为没抛异常时测试会被跳过 |
| 5 | 浮点 / dict / set 怎么断言 | `== pytest.approx(0.3)`（默认 `rel=1e-6`，`abs=` 给绝对容差）；集合先 `sorted()` 再比 | `assert v == 0.3` 直接比二进制浮点；靠 dict/set 的顺序断言 |
| 6 | fixture ↔ JUnit 的什么，放哪 | `@BeforeEach` + 按**参数名**注入；`yield` 前 setup、后 teardown；`scope="function/class/module/session"`；跨文件共享放 **`conftest.py`**（不用 import） | 把状态写进模块级变量；忘放 conftest 后报 "fixture not found" |
| 7 | `@ParameterizedTest` 的对应物，本机能不能用 | `@pytest.mark.parametrize("a, b", [(1, 2), (3, 4)])`；本机判分器用 `_pytest_shim.py` 顶替，**parametrize 和 fixture 都用不了**（测试函数一律零参数调用） | 以为没装 pytest 也能跑参数化；以为 `py -m pytest drills/L14 -q` 现在就能跑 |
| 8 | 六个级别和数字 | `NOTSET 0 / DEBUG 10 / INFO 20 / WARNING 30 / ERROR 40 / CRITICAL 50`，**数字越大越严重** | 按 syslog 直觉写成"越小越严重" |
| 9 | 一条日志会不会被输出（两道门） | `record.levelno >= logger.level` **且** `>= handler.level`，取较严者；**相等也放行**（`should_log(WARNING, WARNING)` → True） | 只看 logger 级别；写成 `>` 漏掉相等边界；logger=INFO 却以为挂了 WARNING 的 handler 照样打 |
| 10 | logger 的层级继承 | 点分名字自动成树；`getEffectiveLevel()` 沿父链找**第一个设过的**级别，`NOTSET`(0)/没设 → 借父级；子级显式设了用自己那份，**比父级更低也听它的** | 以为子 logger 永远等于父级；以为 `NOTSET` 是"全放行"的最低门槛 |
| 11 | `logging.getLevelName` 的两个方向 | `getLevelName("WARNING")` → `30`；认不出来时**不抛异常而回字符串**：`"info"` → `'Level info'`、`25` → `'Level 25'` | 以为返回 `None` 或直接 `ValueError`（练习 1 要你自己判类型转 `ValueError`；练习 5 因此把 25 渲染成 `Level 25` 而不报错） |
| 12 | 库代码怎么写日志（含占位符与堆栈） | 只 `logger = logging.getLogger(__name__)`，**不加 handler、不配置**；`logger.info("uid %s", uid)` 走**惰性格式化**（低于级别不拼串，≈SLF4J 的 `{}`）；堆栈用 `logger.exception("msg")` = `error(..., exc_info=True)`，只能在 `except` 块里 | 在库里写 `logging.basicConfig()` 或模块级 `logging.warning(...)`（隐式配 root）；用 f-string 预格式化；用 `print` 调试 |
| 13 | 生产怎么配日志，测试里怎么抓 | `logging.config.dictConfig({...})` ≈ logback.xml，四个键 `formatters`/`handlers`/`loggers`/`root`，另加 `"disable_existing_loggers": False`；测试抓日志：私有 logger + `propagate=False` + `StreamHandler(io.StringIO())`（≈ `caplog`） | 到处 `setLevel()` 散配；忘了 `disable_existing_loggers` 把自己建好的 logger 关掉；没关 `propagate` 结果 root 又打一份 |
| 14 | timeit ↔ JMH：单次耗时怎么算 | `Timer(stmt).timeit(number)` 给**总**耗时，单次 = 总 / number；`repeat(repeat, number)` 取**最小值**；timeit 自动关 GC。手写计时用 `time.perf_counter()`（单调），别用 `time.time()` | 用 `time.time()` 差值单次采样；忘了除 number；把"必须快于 X ms"写进断言；`number=0` 也照跑（得出 0 秒的假结论） |
| 15 | cProfile 的 `tottime` 与 `cumtime` | `tottime` = 函数**自身**耗时（找热点），`cumtime` = 含被调用者（找链路瓶颈）；`pstats.Stats(...).sort_stats("cumulative").print_stats(10)` | 只按 `tottime` 排序就断言"它最慢"；把一次 profile 的结果当基准数据 |
| 16 | ruff / pylint / mypy 各管什么；PEP8 的函数名规则 | ruff ≈ Checkstyle+SpotBugs（风格 + 可疑写法，顺带 isort）、pylint ≈ PMD（最细也最吵）、mypy 只管**类型**（渐进标注、运行时零强制）；合法函数名 = `re.fullmatch(r"_*[a-z][a-z0-9_]*", name)`，`def` 和 `async def` 都查，报 `L{行号}: N802 ...`，按行号升序 | 以为 mypy 运行时会拦类型错误；用 `name.islower()` 判（`_helper`、`ok_2_name` 误判）；只查 `def` 漏 `async def`；忘了排序 |
| 17 | argparse 参数非法时抛什么 | 把用法打到 **stderr** 再 `SystemExit`，不是 `ValueError`；`-c/--count` 要 `type=int` 才是整数，开关用 `action="store_true"`，`vars(parser.parse_args(argv))` 出字典 | `except ValueError` 去兜（兜不住）；忘写 `type=int` 拿到字符串 `"3"` |
| 18 | 用例之间为什么不能共享对象 | fixture 默认每条新建（`scope="function"`）；模块级可变对象会跨用例残留。`[[0] * 3] * 5` 是 5 个引用指向**同一个**列表（`id` 相同） | 以为 `[[0]*3]*5` 复制了 5 份；拿模块级 list 当"初始数据"，改一条影响全部 |

## 一句话自检（背不出就回讲义 ⑤）

- 三个必踩的坑：库代码里 `basicConfig`/模块级日志污染全局、`assert (cond, "msg")` 元组恒真（且 `python -O` 会删掉所有 assert）、`time.time()` 手搓计时 + 用例共享可变对象。
