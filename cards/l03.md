# L03 闪卡 · 字符串、正则与日期

> 用法：盖住右列，看左列自问自答，答完再对。做错的那行，在"错"列打 ×。
> 复习节奏：完成当天不算，D+1、D+2、D+4、D+7 各过一遍（`py progress.py review` 会告诉你今天该翻哪张）。

| # | 问 | 答 | 错 |
|---|---|---|---|
| 1 | `re.match` / `re.search` / `re.fullmatch` 有什么区别 | match 只从**串首**试；search 任意位置找第一个；fullmatch 要求整串命中 | |
| 2 | Java 的 `matcher.matches()` 对应 Python 哪个函数 | `re.fullmatch`。对应 `re.match` 是错的 | |
| 3 | 校验 QQ 号只允许 5~12 位且首位非 0 | `re.fullmatch(r'[1-9]\d{4,11}', s) is not None` | |
| 4 | 抓手机号，要求两侧不能紧挨数字 | `r'(?<!\d)1[3-9]\d{9}(?!\d)'`，用前后向查找，`\b` 不顶用 | |
| 5 | `findall` 返回什么？有分组时会怎样 | 无分组→匹配串列表；**有一个以上分组→分组内容列表**，整体匹配被丢掉。要对象用 `finditer` | |
| 6 | 命名分组怎么取值 | `m.groupdict()` 全拿，`m['time']` 或 `m.group('time')` 单拿 | |
| 7 | `'.join(items)` 里 items 含 int 会怎样 | `TypeError`。先 `map(str, items)` | |
| 8 | `'a b  c'.split()` 和 `.split(' ')` 结果 | 前者 `['a','b','c']`（合并空白、丢空串）；后者 `['a','b','','c']` | |
| 9 | Python 的 `str.split(regex)` 能当正则用吗 | 不能，参数是**字面串**。要正则切用 `re.split` | |
| 10 | `find` 与 `index` 找不到时分别怎样 | `find` 返回 `-1`；`index` 抛 `ValueError`（`rfind`/`rindex` 同理） | |
| 11 | f-string 里怎么输出 `1,234,567` / `12.30%` / `1.23e+08` | `{x:,}` / `{x:.2%}` / `{x:.2e}` | |
| 12 | f-string 里 `f'{x=}'` 是干什么的 | 调试用，连变量名一起打印：`x=3.14` | |
| 13 | `f'{dt:%Y-%m-%d}'` 冒号后面是什么 | `strftime` 格式符，等价于 `dt.strftime('%Y-%m-%d')` | |
| 14 | `'3'.zfill(5)` 和 `'-3'.zfill(5)` | `'00003'` 和 `'-0003'`，符号位保留在最左 | |
| 15 | 解析 `'2024-03-15 09:23'` 成 datetime | `datetime.strptime(s, '%Y-%m-%d %H:%M')`；Java 的 `yyyy-MM-dd` 字母在这里全是错的 | |
| 16 | `(b - a)` 两个 datetime 相减得到什么，怎么取天数 | `timedelta`，用 `.days`（还有 `.seconds`、`.total_seconds()`） | |
| 17 | `date.weekday()` 周一返回几 | `0`（周五=4，周六=5，周日=6）；`isoweekday()` 才是周一=1 | |
| 18 | 标准库里怎么拿"当月最后一天" | `calendar.monthrange(year, month)[1]` 给天数；`dateutil` 需 pip 安装 | |

## 一句话自检（背不出就回讲义 ⑤）

- 三个坑：`str.split` 不是正则、正则串必须 `r''` 前缀、`re.match` 不等于整串匹配。
