# L10 闪卡 · 文件、JSON 与 CSV

> 用法：盖住右列，看左列自问自答，答完再对。做错的那行，在"错"列打 ×。
> 复习节奏：完成当天不算，D+1、D+2、D+4、D+7 各过一遍（`py progress.py review` 会告诉你今天该翻哪张）。

| # | 问 | 答 | 错 |
|---|---|---|---|
| 1 | Windows 上 `open("a.txt").read()` 默认按什么编码解码 | 操作系统 locale，中文 Windows 就是 **GBK**。所以永远显式 `encoding="utf-8"` | |
| 2 | 模式 `'w'` 和 `'x'` 的区别 | `'w'` 打开即清空原文件；`'x'` 独占创建，文件已存在抛 `FileExistsError` | |
| 3 | 追加写用哪个模式，文件不存在会怎样 | `'a'`，不存在就创建，存在则在尾部追加，不会清空 | |
| 4 | `'rb'` 读回来的类型是什么，能和 `str` 相加吗 | `bytes`，不能。要么 `.decode(encoding)`，要么全程用字节串 | |
| 5 | `str` ↔ `bytes` 怎么转 | `.encode("utf-8")` / `.decode("utf-8")`；编码名写错抛 `LookupError`，字节不合法抛 `UnicodeDecodeError` | |
| 6 | `json.dumps` 默认输出中文长什么样 | `"\u9a86\u660a"`。要 `ensure_ascii=False` 才是中文原样 | |
| 7 | `dump` / `dumps` / `load` / `loads` 分别干什么 | `dumps` 出字符串、`dump` 写文件、`loads` 解析字符串、`load` 读文件 | |
| 8 | `json.dumps({"tags": {"a","b"}})` 的结果 | **抛 `TypeError`**。`set`、`datetime`、自定义类都不在 JSON 的 7 对映射里 | |
| 9 | 怎么让 json 认得 `set` / `date` | 传 `default=函数`，函数返回一个可序列化的替身（`sorted(s)`、`d.isoformat()`） | |
| 10 | dataclass 对象怎么转 JSON | `json.dumps(asdict(obj), ensure_ascii=False)`；反回来 `Cls(**data)` | |
| 11 | Python 的"私有序列化"是什么，能用来存到 Redis 吗 | `pickle`。只认 Python，且**反序列化不可信数据等于执行任意代码**，跨语言一律用 JSON | |
| 12 | `csv.DictReader` 读出来的值是什么类型 | 全是 `str`。数字、日期要自己转 | |
| 13 | 用 csv 模块时 `open(..., newline="")` 为什么必须 | 阻止文本层再翻译一次换行，否则 Windows 上生成的 CSV 会出现空行 | |
| 14 | 字段里含逗号或引号怎么办 | 别 `split(",")`。`csv` 模块会自动加引号，连续两个 `""` 表示一个引号 | |
| 15 | `Path` 的 `name` / `stem` / `suffix` 分别是什么 | `archive.tar.gz` → `'archive.tar.gz'` / `'archive.tar'` / `'.gz'`，suffix 只取最后一段且带点 | |
| 16 | `os.path.join(d, "a.txt")` 的 pathlib 写法 | `Path(d) / "a.txt"`；只想拆字符串不碰磁盘用 `PureWindowsPath` | |
| 17 | 读写 `.xlsx` / Word / PDF 分别用什么库 | `openpyxl`（或 `pandas.to_excel`）/ `python-docx`、`python-pptx` / 读 `pdfminer.six`、写 `reportlab` | |
| 18 | 大文件复制为什么不能 `read()` 一把梭 | 会整份进内存。用 `'rb'` + `read(chunk_size)` 循环，读到空字节串即文件尾 | |

## 一句话自检（背不出就回讲义 ②）

- 三个必踩的坑：`open` 不写 encoding、`str`/`bytes` 混用、`json.dumps` 的 `ensure_ascii` 与 `default=`。
