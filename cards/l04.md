# L04 闪卡 · 函数与一等对象

> 用法：盖住右列，看左列自问自答，答完再对。做错的那行，在"错"列打 ×。
> 复习节奏：完成当天不算，D+1、D+2、D+4、D+7 各过一遍（`py progress.py review` 会告诉你今天该翻哪张）。

| # | 问 | 答 | 错 |
|---|---|---|---|
| 1 | `def f(a, b=1, *args, **kwargs)`，`f(1, 2, 3, x=4)` 里 b/args/kwargs 各是什么 | `b=2`（位置参数顶掉默认值）、`args=(3,)`、`kwargs={'x': 4}` | |
| 2 | 参数在 `def` 里合法的排列顺序 | 无默认值 → 有默认值 → `*args` → 命名关键字 → `**kwargs`；默认值在前会 SyntaxError | |
| 3 | `def f(*, a, b)` 里的 `*` 是什么意思 | a、b 只能用 `f(a=1, b=2)` 传；按位置传会 TypeError | |
| 4 | `def f(a, /)` 里的 `/` 是什么意思 | a 只能按位置传（3.8+），改名不破坏调用方 | |
| 5 | 有 `*args` 时，`f(a, b, True)` 里多出来的 True 会 TypeError 吗 | **不会**，它被 `*args` 吞掉。命名关键字参数只能靠"传名字"来命中 | |
| 6 | 调用侧 `f(*lst, **d)` 是什么 | 解包：列表当位置参数、字典当关键字参数。Java 没有对应语法 | |
| 7 | `def append(item, target=[])` 连续调三次 `append(1)` 的结果 | `[1]`、`[1,1]`、`[1,1,1]` —— 默认列表只在 def 时创建一次，被所有调用共享 | |
| 8 | 可变默认值的正确写法 | `def f(items=None): if items is None: items = []` | |
| 9 | `[lambda: i for i in range(3)]` 调用的结果 | `[2, 2, 2]`。闭包捕获的是变量本身，取值发生在调用时（晚绑定） | |
| 10 | 怎么在推导式里固化 i | `lambda x, i=i: x * i`（默认参数在定义时求值）或再套一层函数 | |
| 11 | LEGB 指什么 | Local → Enclosing → Global → Builtin，**运行时**查找；块（for/if）不是作用域 | |
| 12 | 内层函数要修改外层变量，写什么 | `nonlocal x`；改模块级变量写 `global x`；只读则什么都不用写 | |
| 13 | Python 支持方法重载吗 | 不支持。同名 def 后者覆盖前者；用默认参数 / `*args` / 类型分支解决 | |
| 14 | `sorted(xs, key=len)` 里为什么 len 后面不加括号 | 加括号是**调用**（得到结果），不加是**把函数对象本身**传进去 | |
| 15 | `functools.partial(int, base=2)` 得到什么 | 一个新函数，等价 `lambda s: int(s, base=2)`（偏函数 / 部分应用） | |
| 16 | `compose(f, g)(x)` 等于什么？实现时为什么要 `reversed` | `f(g(x))`：最右边的先执行，所以遍历顺序要反转 | |
| 17 | Python 的 lambda 能写语句吗 | 不能。只有一个表达式，没有 return、没有赋值、没有类型注解 | |
| 18 | 内置 `map`/`filter` 返回什么 | 惰性迭代器，不是列表；要列表 `list(...)`，或者直接用推导式 | |

## 一句话自检（背不出就回讲义 ⑤）

- 三个坑：可变默认值只创建一次、闭包晚绑定、没有重载也没有编译期参数检查。
