# L01 闪卡 · 语法差异地图

> 用法：盖住右列，看左列自问自答，答完再对。做错的那行，在"错"列打 ×。
> 复习节奏：完成当天不算，D+1、D+2、D+4、D+7 各过一遍（`py progress.py review` 会告诉你今天该翻哪张）。

| # | 问 | 答 | 错 |
|---|---|---|---|
| 1 | `-7 % 3` 在 Python 等于几？为什么和 Java 不同 | `2`。Python 取模结果符号跟**除数**，Java 跟被除数 | |
| 2 | `-7 // 2` 等于几？ | `-4`。`//` 向下取整（朝负无穷），不是截断小数 | |
| 3 | `7 / 2` 和 `7 // 2` 分别是什么 | `3.5` 和 `3`。`/` 永远是真除法，返回 float | |
| 4 | Python 里怎么算 2 的 10 次方 | `2 ** 10`，不需要 `Math.pow` | |
| 5 | 哪些值在 `if x:` 里是假 | `0, 0.0, "", [], {}, set(), None, False`；其余皆真（非空集合 `[0]` 是**真**） | |
| 6 | 判"变量没赋值/为空对象"该写什么 | `if x is None:`。`if x:` 会把 `0`、`[]` 一起误判 | |
| 7 | Python 的 `for/else` 什么时候走 else | 循环**没有被 break** 打断时。读作"找了一圈没找到，否则……" | |
| 8 | 交换两个变量 | `a, b = b, a`，不需要临时变量 | |
| 9 | Java 的 `for (int i=0;i<10;i++)` 怎么写 | `for i in range(10):`。`range` 左闭右开；Python 没有 `i++` | |
| 10 | 带下标遍历列表的地道写法 | `for i, x in enumerate(xs):`，可用 `enumerate(xs, start=1)` | |
| 11 | 并行遍历两个列表 | `zip(a, b)`，长度不等时截断到短的那个 | |
| 12 | Python 有没有块级作用域 | 没有。只有函数级 + LEGB。`for` 里定义的变量出了循环还在 | |
| 13 | 类型挂在什么上 | 挂在**对象**上，变量只是标签。`x = 1; x = "a"` 合法 | |
| 14 | Python 的 int 会溢出吗 | 不会，任意精度，不需要 BigInteger | |
| 15 | `if x:` 中 x 是空列表 `[]` 进不进分支 | 不进，空容器为假 | |
| 16 | Python 的三元表达式 | `b if a else c`，读的顺序和 Java 的 `a ? b : c` 相反 | |
| 17 | 循环里拼字符串为什么用 `''.join(parts)` | `str` 不可变，`+=` 每轮复制一遍，O(n²) | |
| 18 | `match/case` 从哪个版本开始有 | 3.10+。`case _:` 是 default，且不需要 `break` | |

## 一句话自检（背不出就回讲义 ②）

- 三个 Java 老手必踩的坑是：`/` 已是真除法、`if x:` 不等于 `x is not None`、循环变量不出作用域。
