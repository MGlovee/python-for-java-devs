# L11 闪卡 · HTTP 与爬虫最小集

> 用法：盖住右列，看左列自问自答，答完再对。做错的那行，在"错"列打 ×。
> 复习节奏：完成当天不算，D+1、D+2、D+4、D+7 各过一遍（`py progress.py review` 会告诉你今天该翻哪张）。

| # | 问 | 答 | 错 |
|---|---|---|---|
| 1 | `urllib.request.urlopen(...).read()` 返回什么类型 | `bytes`。要 `.decode(charset)` 才是 `str` | |
| 2 | `urllib` 遇到 404 / 500 会怎样 | 抛 `HTTPError`（可读 `.code`、`.read()`）；连不上/超时是 `URLError` | |
| 3 | `requests` 遇到 4xx/500 会怎样 | **正常返回** `Response`，得自己 `resp.raise_for_status()` | |
| 4 | 超时怎么设 | `urlopen(url, timeout=5)`；`requests.get(url, timeout=(3, 7))` 分别是连接/读取 | |
| 5 | 拼查询串该用什么，别做什么 | `urlencode(dict)`；别手拼 `+ "?a=1"`，会丢原参数、也不转义 `&`/`=`/中文 | |
| 6 | `urljoin("https://h/dir/p.html", "../a")` 结果 | `https://h/a`。相对路径、`//cdn/x`（继承协议）、`/x`（站点根）它全管 | |
| 7 | 爬虫为什么必须带 `User-Agent` | 很多站（如豆瓣）识别到空 UA / 默认 Python UA 直接拒。伪装浏览器是第一步 | |
| 8 | `robots.txt` 里 `Disallow:` 空值是什么意思 | 该组**全放开**。`Disallow: /` 才是全禁止 | |
| 9 | robots 是法律吗 | 不是，是君子协议；但打官司时"是否遵守"会被当作过错证据，仍需控制频率、尊重版权 | |
| 10 | 从 HTML 取数据的三种方式与依赖 | 正则 `re`（标准库）/ XPath（`lxml`）/ CSS 选择器（`beautifulsoup4`、`pyquery`） | |
| 11 | 不用三方包还想结构化解析 HTML，有什么标准库选项 | `html.parser.HTMLParser` 子类 + `html.unescape` 还原实体 | |
| 12 | 正则解析 HTML 最典型的翻车点 | 注释和 `<script>` 里的假标签也会被匹配；属性顺序/换行/嵌套一变全错 | |
| 13 | 页面数据是 JS 动态渲染出来的，先试什么 | 先看 Network 里的 XHR/fetch JSON 接口（最省），再考虑 Selenium（原文 64） | |
| 14 | 收到 429 该做什么 | 停下并按 `Retry-After` / 指数退避等待、降并发；不是换 IP 硬闯 | |
| 15 | 指数退避 + 抖动的公式直觉 | 第 i 次等 `min(base * factor**i, cap)`，再 `+ random()` 一点抖动，避免同步重试风暴 | |
| 16 | 只重试哪些请求 | 幂等的（GET、HEAD）和 5xx/超时/429；POST 无幂等键时别自动重发 | |
| 17 | 爬虫 URL 去重为什么要规范化 | 大小写、参数顺序、fragment 会让同一页面看起来像多个 URL：先 `canonical_url` 再判重 | |
| 18 | `requests.Session()` 解决什么 | 复用 TCP 连接 + 自动维持 Cookie（登录态），批量抓取时比裸 `get` 快得多 | |

## 一句话自检（背不出就回讲义 ②）

- 三个必踩的坑：`urllib` 抛异常 vs `requests` 不抛、`.read()` 是 bytes、相对链接与参数必须交给 `urljoin`/`urlencode`。
