|---|---|---|---|
| 1 | Java 的 `ArrayList` / `LinkedHashMap` / `HashSet` 分别对应 Python 什么 | `list` / `dict`（3.7+ 保证插入序）/ `set` | |
| 2 | 频繁头部删除/插入该用什么 | `collections.deque`，`list.pop(0)` 是 O(n) | |
| 3 | 计数用什么类 | `collections.Counter`，`Counter(words).most_common(3)` 取前 3 | |

| 13 | `d["k"]` 与 `d.get("k")` 区别 | 前者缺键抛 `KeyError`，后者返回 None（第二参数给默认值） | |

## 一句话自检

四件套：`list` 有序可变可重复 / `tuple` 不可变可哈希 / `dict` 插入序键唯一 / `set` 无序去重 O(1) 查找。
补位三件套：`Counter` 计数、`defaultdict` 分组、`deque` 两头进出。
